## Styling

The components use a consistent styling approach:

- `appearance` controls the visual variant
- `hoverStyle` controls the interaction behavior
- `customClass` is intended for additional project-specific classes, for example to pass custom CSS classes from an application

Deprecated fields such as `classStyle` and `classStyles` should not be used in new implementations.

Example for application-specific styling via `customClass` and CSS variables:

```html
<filled-btn-component label="Save" customClass="my-app-primary-btn">
</filled-btn-component>
```

```scss
.my-app-primary-btn {
    --filled-btn-bg: #d9d9d9;
    --filled-btn-text-color: #1f2937;
    --filled-btn-hover-bg: #cfcfcf;
}
```
