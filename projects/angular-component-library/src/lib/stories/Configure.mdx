## Styling

Die Komponenten verwenden ein einheitliches Styling-Konzept:

- `appearance` steuert die visuelle Variante
- `hoverStyle` steuert das Interaktionsverhalten
- `customClass` ist für zusätzliche projektspezifische Klassen gedacht

Veraltete Felder wie `classStyle` und `classStyles` sollten in neuen Implementierungen nicht mehr verwendet werden.
